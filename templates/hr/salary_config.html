How It Works
  • New Employees (First 2 Months) = Leave, Late & Security ({{ config.new_employee_security_pct }}%) apply. PF, Tax, Van/Child, Bonus skipped.
  • Allowances = Basic Salary x Percentage / 100
  • Per Day Salary = Basic Salary / Total Working Days
  • Leave Deduction = (Absent - Max Allowed Leaves) x Per Day
  • Late Deduction = Every {{ config.late_deduction_per }} lates = Half day salary
  • Bonus = 0 absent & 0 leaves → {{ config.bonus_per_day }} per day OR {{ config.bonus_percentage }}% of basic
  • Gross = Basic + Increment + Allowances + Bonus - Leave Ded - Late Ded
  • Tax = Gross x {{ config.tax_percentage }}%
  • Net = Gross - (All Deductions)
